## Methodology

- Every case is a disposable git repository seeded with exactly the defect class in its row.
- Cells are pre-registered: ✅/❌ where the rival documents coverage for that class;
  `flagged`/`quiet` (🔶) where the class is outside its documented scope; `n/e` where no
  evaluation applies. `noise:` counts findings on clean baselines — those are false-positive
  signals for the rival, not defects.
- Fixtures are codebase-doctor's corpus; rival sensitivity on synthetic tokens can differ
  from real-world credentials and is reported, not concealed.
- The `(+advisories)` column is codebase-doctor run with the opt-in `--with-advisories`
  network flag (OSV, point-in-time). It is evaluated only on the dependency cases and
  `n/e` elsewhere; the default column stays fully offline and deterministic.

## What this shows, including where codebase-doctor loses

- `vulnerable-lockfile`: osv-scanner catches known-vulnerable dependencies from the OSV
  database, and codebase-doctor catches the same class only in the opt-in `(+advisories)`
  column. Offline-by-default is a deliberate trade: deterministic audits never call the
  network, so the default column shows the capability gap and the advisory column shows
  the fix. For supply-chain vulns in routine use, enable `--with-advisories` or run the
  rival first.
- `secrets-history` (original fixture): the seeded `github_pat_` value is not a
  provider-valid format (fine-grained PATs are longer), so provider-format linters miss it
  while codebase-doctor's relaxed detector catches it. `secrets-history-realistic` gives
  rivals a realistic-length token in history and shows gitleaks catching the same class.
- Check the informational columns for classes rivals flag that codebase-doctor does not and
  vice versa. Cases with no engaged rival are codebase-doctor-unique coverage in this
  corpus, not proof of superiority.

```bash
# Semgrep (public registry rulesets; semgrep login unlocks more rules and changes results)
pipx install semgrep==1.180.0
```

## Limitations

- Semgrep CE without `semgrep login` runs a reduced public ruleset; its real-world recall is
  higher than this snapshot shows. The pinned version and rule source are recorded above.
- Rival scanners target different threat models; `n/e` cells are outside-scope classes, not
  defeats. Severities are not normalized across tools and no attempt is made to rank them.
- 21 synthetic fixtures cannot represent a real repository's noise profile. The clean-control
  rows are the honest noise signal available at this size.
